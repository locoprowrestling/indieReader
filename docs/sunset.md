# indieReader Sunset

indieReader is sunsetting as of Monday, July 6th, 2026.

The pre-sunset site state is archived in git tag
`archive/pre-sunset-2026-07-06`.

GitHub Actions workflows were moved out of `.github/workflows/` into
`.github/workflows-disabled/` so scheduled fetches, generated posts, tweets, and
Pages deploys no longer run automatically.
